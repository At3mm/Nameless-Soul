# Quản lý vật phẩm

Hướng dẫn hiện tại: [Item Manager](HUONG_DAN_ITEM_MANAGER.md).

Tool đã hỗ trợ tạo vật phẩm cấu hình chung ở Resources/Items, sửa ID/tên/mô tả/icon, tab túi đồ, vai trò, độ hiếm, giới hạn cộng dồn, hiệu ứng, tiêu hao/tái sử dụng và giá mua/bán. Vật phẩm mới dùng được ở nhiệm vụ, cửa hàng, pickup, Enemy Item Drop và ô dùng nhanh; đồ cũ vẫn giữ GUID/save hiện có.

Đổi ID ảnh hưởng save cũ. Riêng Bùa hồi quy cũ giữ ID hệ thống. Cơ chế hiệu ứng hoàn toàn mới vẫn cần viết logic một lần.
