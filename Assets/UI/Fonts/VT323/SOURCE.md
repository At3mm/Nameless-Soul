Downloaded 2026-11-08. License: SIL Open Font License 1.1; see OFL.txt.

The game uses VT323 across HUD, menus, inventory, dialogue, shops, world notices and runtime labels. Font asset: Assets/Resources/Fonts/VT323-Regular.ttf. GameFont.Current resolves the shared runtime font. The previous font remains in Assets/UI/Fonts/PixelifySans for rollback.

Pause/inventory/victory use a 1.25x text-size adjustment when the selected font name starts with VT323 to compensate for its narrower/smaller glyph design. Other fonts retain their original sizing.
