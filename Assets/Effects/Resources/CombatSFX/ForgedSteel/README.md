# Forged Steel - original sword synthesis

13 newly synthesized mono PCM WAV files at 44.1 kHz: 3 light impacts, 3 heavy impacts, 3 light swings, 3 heavy swings and parry. Generated by Assets/Effects/Editor/GenerateForgedSteel.py using fresh seeded noise, independent inharmonic modal oscillators, envelope design, mild saturation and short early reflections.

The imported reference recordings guided the desired transient/body/tail balance. Only coarse measurements (duration, RMS, spectral centroid) are retained for comparison; reference PCM is never mixed, copied or used as resynthesis excitation. Synthesis is performed before the optional measurement pass. This is an approximation of the impact character, not a claim of an identical recording or legal clearance by the reference vendor.

DefaultCombatAudio now uses these original files in both Editor and builds. The automatic Editor override to Epidemic PreviewCombatAudio was removed. The downloaded source media stays under Editor as inactive reference material. Other SFX (dash, buffs/debuffs, healing, cleanse and skill cast) are unchanged.

The prior configuration is backed up at Assets/Effects/Editor/CombatAudioBeforeForgedSteel.asset. Old generated WAVs were retained. SynthesisReport.json contains level/length checks and coarse reference metrics. All output peaks are 0.68 with edge fades and 3 variants per attack category. Direct auditory comparison was not available; judge subjective similarity in combat.
